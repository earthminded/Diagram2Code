Техническое задание
===================

Требования функциональных характеристик
-----------------------
#. Пользователь видит графическое поле для построения диаграмм и боковую панель с деревом классов.
#. Пользователь может создать новый элемент диаграммы, кликнув левой кнопкой мыши по пустому месту на холсте в режиме создания элементов.
#. Пользователь может выделять и свободно перемещать созданные элементы по холсту с помощью зажатой левой кнопки мыши.
#. Пользователь видит автоматически обновляемое дерево всех созданных классов в боковой панели: для каждого класса отображаются тип и имя, а также вложенные списки его атрибутов и операций.
#. Пользователь может удалить все элементы с холста и очистить дерево с помощью кнопки "Очистить поле".
#. Пользователь может переключаться между режимом выделения/перемещения и режимом создания элементов с помощью кнопки-иконки на верхней панели инструментов.
#. Пользователь может открыть редактор класса тремя способами: нажатием на иконку «+», появляющуюся на классе при наведении курсора, двойным щелчком по классу на холсте или двойным щелчком по записи класса (или любой вложенной записи) в боковом дереве.
#. Редактор класса представляет собой диалоговое окно с вкладками «Атрибуты», «Операции (Методы)» и «Документация». Атрибуты и операции редактируются в виде таблиц.
#. Пользователь может добавлять атрибуты и операции в таблицы редактора, задавая для них модификатор видимости («+», «-» или «#»), имя и тип данных. Для операции дополнительно задаются параметры и возвращаемый тип.
#. Пользователь может удалять отдельные атрибуты и операции, выделив строку в таблице редактора и нажав кнопку «Удалить выбранный» («Удалить выбранную»).
#. Пользователь может ввести текстовое описание класса на вкладке «Документация».
#. Пользователь может переключаться между классами внутри редактора с помощью выпадающего списка «Выбранный класс».
#. Пользователь может добавить собственный тип данных в общую коллекцию типов, после чего этот тип становится доступен в выпадающих списках всех атрибутов и операций. По умолчанию доступны типы int, float, double, string, bool, void и char.
#. Пользователь может сохранить изменения кнопкой «Сохранить изменения» или закрыть редактор без сохранения кнопкой «Отмена».
#. Пользователь может удалять выделенные классы с помощью клавиши Delete на клавиатуре.
#. Пользователь может удалить отдельный класс, нажав на кнопку с иконкой корзины рядом с ним в боковом дереве.

Сценарий использования программы:
---------------------------------
1. Пользователь хочет создать новый элемент диаграммы.
Основной успешный сценарий:
1) Пользователь включает режим создания элементов и нажимает левую кнопку мыши на свободной области графического поля.
2) В месте нажатия левой кнопки мыши создаётся прямоугольник, представляющий новый элемент со стандартным сгенерированным именем.
3) В боковом дереве появляется новая запись, содержащая тип и имя созданного элемента, с двумя пустыми вложенными разделами «Атрибуты» и «Операции».

2. Пользователь хочет изменить расположение элемента.
Основной успешный сценарий:
1) Пользователь наводит курсор на существующий прямоугольник и зажимает левую кнопку мыши.
2) Пользователь перемещает мышь, перетаскивая элемент в нужную точку графического поля.
3) Модель данных автоматически обновляет внутренние координаты элемента при его перемещении.

3. Пользователь хочет очистить рабочую область.
Основной успешный сценарий:
1) Пользователь нажимает на кнопку "Очистить поле".
2) Все графические объекты удаляются с холста.
3) Боковое дерево полностью очищается.
4) Внутренний счетчик создания элементов сбрасывается в исходное состояние.

4. Пользователь хочет переключить режим работы холста.
Основной успешный сценарий:
1) Пользователь нажимает на кнопку добавления на верхней панели инструментов.
2) Курсор меняется на крестик, программа переходит в режим создания элементов по клику на пустое место.
3) Пользователь повторно нажимает на кнопку (отжимает её).
4) Курсор возвращается к стандартному виду, программа переходит в режим выделения (в том числе массового выделения рамкой) и перемещения.

5. Пользователь хочет добавить атрибут или операцию в класс.
Основной успешный сценарий:
1) Пользователь наводит курсор мыши на прямоугольник класса на холсте. В правом верхнем углу появляется иконка «+».
2) Пользователь нажимает на иконку «+». Открывается редактор класса с вкладками «Атрибуты», «Операции (Методы)» и «Документация».
3) Пользователь выбирает нужную вкладку и нажимает кнопку «Добавить атрибут» или «Добавить операцию». В таблице появляется новая строка.
4) Пользователь выбирает видимость и тип данных из выпадающих списков, вводит имя (а для операции ещё и параметры), затем нажимает «Сохранить изменения».
5) Внутри прямоугольника класса появляется новая строка с данными, отделенная линией. Прямоугольник автоматически растягивается по высоте.
6) В боковом дереве запись добавляется в раздел «Атрибуты» или «Операции» соответствующего класса.

6. Пользователь хочет открыть редактор класса из бокового дерева или двойным щелчком.
Основной успешный сценарий:
1) Пользователь дважды щелкает левой кнопкой мыши по прямоугольнику класса на холсте либо по записи класса (или вложенной записи) в боковом дереве.
2) Открывается редактор класса с текущими атрибутами, операциями и документацией выбранного класса.

7. Пользователь хочет изменить видимость атрибута или операции.
Основной успешный сценарий:
1) Пользователь открывает редактор класса и переходит на вкладку «Атрибуты» или «Операции (Методы)».
2) Пользователь выбирает в выпадающем списке «Видимость» нужной строки один из символов: «+», «-» или «#».
3) Пользователь нажимает «Сохранить изменения». Символ видимости обновляется на прямоугольнике класса и в боковом дереве.

8. Пользователь хочет удалить отдельный атрибут или операцию.
Основной успешный сценарий:
1) Пользователь открывает редактор класса и выделяет строку нужного атрибута или операции в таблице.
2) Пользователь нажимает кнопку «Удалить выбранный» («Удалить выбранную»). Строка исчезает из таблицы.
3) Пользователь нажимает «Сохранить изменения». Строка исчезает с прямоугольника класса и из бокового дерева, а размер прямоугольника автоматически уменьшается.

9. Пользователь хочет добавить описание класса.
Основной успешный сценарий:
1) Пользователь открывает редактор класса и переходит на вкладку «Документация».
2) Пользователь вводит текст описания в поле ввода.
3) Пользователь нажимает «Сохранить изменения». Описание сохраняется в модели данных.

10. Пользователь хочет добавить новый тип данных.
Основной успешный сценарий:
1) Пользователь открывает редактор класса и вводит название нового типа (например, MyClass) в поле внизу окна.
2) Пользователь нажимает кнопку «Добавить в коллекцию типов».
3) Появляется сообщение об успешном добавлении, поле ввода очищается.
4) Новый тип становится доступен в выпадающих списках типов данных атрибутов и операций.

11. Пользователь хочет отредактировать другой класс, не закрывая редактор.
Основной успешный сценарий:
1) Пользователь открывает редактор класса и выбирает другой класс в выпадающем списке «Выбранный класс».
2) В таблицах и на вкладке документации отображаются данные выбранного класса.
3) Пользователь вносит изменения и нажимает «Сохранить изменения». Изменения сохраняются для выбранного в данный момент класса.

12. Пользователь хочет удалить конкретный класс.
Основной успешный сценарий:
1) Пользователь выделяет один или несколько классов на холсте левым кликом мыши или рамкой выделения и нажимает клавишу Delete на клавиатуре. Либо нажимает на кнопку с иконкой корзины рядом с нужным классом в боковом дереве.
2) Классы удаляются с холста и из бокового дерева.
